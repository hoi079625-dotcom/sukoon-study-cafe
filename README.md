# سكون | SUKOON Study Café

موقع تعريفي ثنائي اللغة لمقهى هادئ مخصص للدراسة والعمل. صُمم كمشروع عملي لمادة الحوسبة السحابية، ويستخدم HTML وCSS وJavaScript فقط، لذلك يمكن استضافته على GitHub Pages دون خادم خلفي أو قاعدة بيانات.

## المزايا

يحتوي الموقع على واجهة رئيسية، تعريف بالفكرة، قائمة تفاعلية حسب التصنيف، معرض بصري، مميزات المساحة، آراء الزوار، فريق العمل، معلومات الزيارة، ونموذج تواصل تجريبي. يمكن التبديل بين العربية والإنجليزية من زر اللغة في أعلى الصفحة.

## التشغيل المحلي

يمكن تشغيله من مجلد المشروع بالأمر التالي:

```bash
python3 -m http.server 3000
```

ثم افتح `http://localhost:3000` في المتصفح.

## الرفع على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع ملفات المشروع إلى الفرع `main`.
3. من **Settings → Pages** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/root` ثم اضغط **Save**.
5. بعد اكتمال النشر سيظهر رابط الموقع في صفحة GitHub Pages.

> نموذج التواصل تفاعلي محليًا فقط؛ لا يرسل بيانات فعلية لأنه مشروع موقع ثابت.
